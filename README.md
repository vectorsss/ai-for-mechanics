# AI for Mechanics: companion code for the lecture series

Neural networks for problems in solid mechanics. Each task is a small,
self-contained problem with its own folder:
the data are generated by a classical solver, then networks learn to replace
it. Everything runs on a laptop CPU; no GPU and no downloaded data are needed.

| folder | task | lecture |
|---|---|---|
| [`01-cnn-composite-stress/`](01-cnn-composite-stress/) | Task A: stress map of a fibre composite plate from its fibre layout (image to image); FEM data, MLP and U-Net | Lecture 1: Convolutional Neural Networks |

## Setup

Python 3.9 or newer.

```sh
pip install -r requirements.txt   # numpy, scipy, matplotlib, torch
```

Then follow the README in the task folder, e.g.
`cd 01-cnn-composite-stress && python fem.py`. Folders are numbered in
lecture order: `NN-<method>-<problem>`.
